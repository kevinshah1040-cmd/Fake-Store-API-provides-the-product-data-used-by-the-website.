🛒 E-Commerce Website — Fake Store API
About the Project

This project is a modern e-commerce website that uses the Fake Store API to dynamically fetch and display products. It provides users with an online shopping-like experience with product listings, categories, product details, and an interactive interface.

✨ Features
🛍️ Product listing
🔍 Product search
🗂️ Product categories
📦 Product details
🛒 Add-to-cart functionality
💰 Product prices and ratings
📱 Responsive design
⚡ Dynamic API-based product data
🎨 Modern and interactive UI
🛠️ Technologies Used
HTML5
CSS3
JavaScript
Fake Store API
REST API
🔗 API Used

Fake Store API — provides the product data used by the website.
